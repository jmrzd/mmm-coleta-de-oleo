## 📖 Sobre

O projeto apresenta a MMM com uma identidade visual em **preto + dourado**, conteúdo focado em coleta responsável, orientação sobre separação e armazenamento e CTAs diretos para o WhatsApp.

A versão deste repositório foi estruturada em **React + Vite** com base na landing page publicada no ChatGPT Sites.

## ✨ Seções

- Hero com mascote e CTA
- Apresentação da MMM
- Tipos de óleo
- Orientações para óleo vegetal usado
- Processo em 3 passos
- Impacto ambiental
- FAQ
- Contato direto pelo WhatsApp
- Footer com crédito de desenvolvimento

## 📱 Responsividade

A interface possui ajustes para desktop, tablet e smartphones. No mobile, o personagem permanece ao lado do conteúdo principal e o enquadramento evita cortar o boné.

## 🚀 Rodando localmente

```bash
git clone https://github.com/jmrzd/mmm-coleta-de-oleo.git
cd mmm-coleta-de-oleo
npm install
npm run dev
```

## 📦 Build

```bash
npm run build
```
