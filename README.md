## 📖 Sobre o projeto

A **MMM Coleta de Óleo** atua na coleta de óleo usado, contribuindo para que esse material tenha uma destinação adequada e possa retornar à cadeia produtiva de forma responsável.

Este projeto consiste em uma **landing page institucional moderna, responsiva e focada em conversão**, criada para fortalecer a presença digital da empresa e facilitar o contato entre a MMM e seus clientes.

A proposta do site é apresentar de maneira clara:

- Quem é a MMM;
- Como funciona o processo de coleta;
- Quais materiais são atendidos;
- Quem pode solicitar a coleta;
- A importância da destinação adequada do óleo;
- Os canais de contato da empresa.

A identidade visual do projeto utiliza principalmente tons de **preto, amarelo e dourado**, seguindo a comunicação visual da MMM Coleta de Óleo.

---

## 🎯 Objetivos

O site possui como principais objetivos:

- Apresentar a **MMM Coleta de Óleo** de forma profissional;
- Fortalecer a presença digital da empresa;
- Explicar de forma simples como funciona a coleta;
- Apresentar os tipos de óleo e materiais atendidos;
- Mostrar a importância da destinação responsável;
- Facilitar o contato com potenciais clientes;
- Direcionar rapidamente o usuário para solicitar uma coleta;
- Criar uma experiência moderna em celulares e computadores;
- Gerar maior confiança na marca;
- Transformar visitantes em novos clientes e parceiros.

## ✨ Principais recursos

### 🏠 Hero Section

Seção principal da página, responsável pela primeira impressão do usuário.

A Hero apresentará:

- Identidade visual da MMM;
- Chamada comercial;
- Mensagem principal da empresa;
- Mascote da marca;
- Botão para solicitar coleta;
- Acesso rápido aos principais serviços.

---

### 🛢️ O que coletamos

Área destinada à apresentação dos materiais e tipos de óleo atendidos pela empresa.

Cada categoria poderá possuir informações próprias para facilitar a identificação do material pelo cliente.

---

### ♻️ Como funciona

O processo será apresentado de maneira simples e visual.

```text
Armazenamento → Solicitação → Coleta → Destinação responsável
```

O objetivo é permitir que qualquer visitante entenda rapidamente como funciona o serviço da MMM.

---

### 🏢 Quem atendemos

A landing page apresentará os principais perfis de clientes atendidos pela empresa, podendo incluir:

- Restaurantes;
- Lanchonetes;
- Bares;
- Cozinhas comerciais;
- Empresas;
- Estabelecimentos que utilizam óleo regularmente;
- Outros parceiros comerciais.

---

### 🌱 Sustentabilidade

Uma seção dedicada a explicar a importância da coleta e da destinação adequada do óleo usado.

A proposta é conscientizar o visitante e demonstrar que o descarte correto contribui para:

- Redução do descarte inadequado;
- Reaproveitamento de resíduos;
- Preservação ambiental;
- Economia circular;
- Destinação responsável do material coletado.

---

### 💰 Óleo usado é dinheiro de volta

Uma das principais mensagens comerciais da MMM.

A página poderá destacar o valor do óleo usado como um material que pode ser coletado, reaproveitado e reinserido na cadeia produtiva.

---

### 📲 Contato rápido

Botões de contato serão posicionados estrategicamente ao longo da página para permitir que o visitante solicite uma coleta sem precisar procurar pelo formulário ou telefone.

A principal integração planejada é com o **WhatsApp**.

## 🚀 Executando o projeto localmente

### 1. Clone o repositório

```bash
git clone https://github.com/jmrzd/mmm-coleta-de-oleo.git
```

---

### 2. Entre na pasta do projeto

```bash
cd mmm-coleta-de-oleo
```

---

### 3. Instale as dependências

```bash
npm install
```

---

### 4. Execute o ambiente de desenvolvimento

```bash
npm run dev
```

---

### 5. Abra no navegador

O Vite exibirá no terminal o endereço local da aplicação.

Normalmente:

```text
http://localhost:5173
```

---

## 📦 Build de produção

Para gerar uma versão otimizada da aplicação:

```bash
npm run build
```

Os arquivos finais serão gerados dentro da pasta:

```text
dist/
```
