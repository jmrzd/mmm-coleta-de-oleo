# Assets

Organização planejada para os arquivos visuais da MMM:

- `images/` — imagens gerais da landing page
- `icons/` — ícones e elementos gráficos
- `logos/` — versões do logotipo MMM
- `mascot/` — artes e variações do mascote

Os arquivos finais serão adicionados conforme o design da landing page for aprovado.
